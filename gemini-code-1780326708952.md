# Component Architecture Specification: Penlink Homepage Agile Updates

## 1. System Overview & Technical Stack
- **Target Environment:** Responsive Web Layout (Desktop Base: 1440px canvas).
- **Core Requirement:** High agility, component-driven architecture. Every module must be fully responsive, supporting swappable layout directions, text wrapping safely without breaking containers, dynamic content injection, and interchangeable media asset blocks without requiring hard-coded structure changes.
- **Primary Typography Token:** `Plus Jakarta Sans`
  - Headers/Titles: Tracking `-2%`, Font-Weight: Bold/ExtraBold.
  - Sub-kickers/Labels: Tracking `+6%`, Text-Transform: Uppercase.

---

## 2. Design Tokens & Color Matrix

### 2.1 Dark UI Palettes (Hero & Console)
- **Primary Base Background:** Linear Gradient from `#0a1838` (Top) to `#04102a` (Bottom).
- **Brand Glow Accent 1 (Blue):** `#3472f4` (Applied with 18% opacity as a soft radial wash).
- **Brand Glow Accent 2 (Teal/Mint):** `#00dcc3` (Applied with 14% opacity as a soft radial wash).
- **Text Gradient Accent:** Linear Gradient from `#00dcc3` (Teal) to `#daf355` (Pale Lime).

### 2.2 Adaptive Light UI Swatches (Mission Section Card Backgrounds)
The system must support 6 distinct runtime color states for container surfaces, ensuring semantic text contrast scales dynamically:
1. `cream` (Warm Paper): `#fbf9f4`
2. `gray` (Light Gray): `#f4f5f7` (or brand equivalent light gray)
3. `blue` (Pale Blue): `#eef3fc`
4. `lime` (Pale Lime): `#f6fad9`
5. `cyan-mint` (Cyan Mint): `#e6faf6`
6. `white` (Pure White): `#ffffff`
